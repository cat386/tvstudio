# Проверка и обновление документации TVStudio

Дата: 27 ноября 2026 года.

## Основание и объём

Сверены локальные файлы репозитория, а не состояние удалённой ветки.
Изменены только README.md, docs/guide.md, examples/README.md, src/help.txt
и этот отчёт. Коммит и отправка в GitHub не выполнялись.

Git в текущей среде не позволил прочитать рабочее дерево: команды возвращали
«this operation must be run in a work tree» либо «Permission denied».
Поэтому порядок коммитов документации и реализации не установлен.
Актуальность оценена сопоставлением текста с доступными исходниками,
а сохранность исходников и тестов — сравнением контрольных сумм.

## Основные изменения

- Добавлены карта меню и отдельные сценарии для обычного Rust-проекта,
  формы, диагностики сборки, LSP Hover и локального Git-коммита.
- Уточнён запуск через --bin tvstudio, Git-зависимость самой студии
  и отдельная потребность тестов/примеров в соседней tvision-rs.
- Описаны изолированные настройки через TVSTUDIO_CONFIG.
- Исправлены ширина диалога параметров среды (90 колонок), названия
  разделов и полей «Сервер Rust» / «Сервер TOML».
- Уточнены F12 в дизайнере и редакторе, поиск F3, замена Ctrl+H,
  закрытие Alt+F3 и различие Ctrl+Y в дизайнере и редакторе.
- Описаны курсор внутри автопары, буквальная вставка командами студии
  и ограничение вставки средствами терминала.
- Добавлен Hover: запрос через 400 мс, зависимость от сервера и терминала,
  скрытие, защита от устаревших ответов, усечение длинного текста.
- Приведены фактические пути «Проект → Git» и подписи кнопок панели.
- Исправлен конфликт команды GOODS с существующей ABOUT=100
  в учебном примере; новые команды начинаются с 101.
- Уточнены необязательное автосохранение перед сборкой, предупреждения
  модели и отсутствие отдельного фонового потока в exec_dialog_idle.
- Снято обещание полностью готового «Склада»: прямо обозначены части
  main.rs и самостоятельные задания.
- PDF обозначен как архивный, актуальным источником выбран Markdown.

## Выполненные проверки

1. Сопоставлены перечисленные команды, поля, условия и ограничения
   с локальной реализацией.
2. Запущен существующий тест help_file_parses на HeadlessBackend;
   он прошёл. Это проверка разбора справки, не её ручного просмотра.
3. Дополнительно проверены локальные ссылки Markdown, ссылки тем справки,
   уникальность номеров команд в таблице «Склада» и пример Rust для Hover.
4. Проверены контрольные суммы исходников и тестов: кроме src/help.txt,
   изменений в этих каталогах нет. Артефакты проверки вынесены за репозиторий.

## Не проверено и оставшиеся пробелы

- Живой интерфейс недоступен инструменту управления окнами; все новые
  пошаговые сценарии описывают ожидаемый результат по реализации,
  а не фактически выполненный ручной сеанс.
- Внешние rust-analyzer и crates-lsp, установка инструментов,
  сетевые запросы crates.io, SSH и credential helpers в этом обновлении
  не запускались. Состав подсказок и исправлений зависит от сервера.
- Сценарии Git не выполнялись над пользовательским репозиторием:
  коммиты, переключения веток, pull и push не производились.
- Полная программа «Склад» из фрагментов не собрана. Поставщики,
  поиск и хранение данных остаются учебными заданиями.
- docs/guide.pdf не пересоздан; ссылка помечена как архивная.
  Для актуального содержания используйте docs/guide.md.
- Перенос и внешний вид длинных страниц справки вручную не проверены.
- Не обещается, что все диалоги помещаются в терминале 80×25:
  текущее окно параметров среды шире.
